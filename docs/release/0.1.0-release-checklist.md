## Remaining blockers to a public 0.1.0

1. `R-LICENSE` — license decision required (owner). Binding reason for public distribution = NO.
2. Full interactive install smoke (`R-GUI-SMOKE`): window render, Settings, create a SQLite
   connection, `SELECT 1;`, clean close and relaunch persistence — runbook `14-install-smoke.txt`
   §8. Extraction, launch and file-level state reuse are already done, including on the
   CI-produced artifact of run `34860902181`.
3. Runtime evidence for V01-01…V01-05, or an explicit decision to release without it.
4. Windows/Linux runtime (`R-WINLINUX`) — requires hosts; `BUILD_VERIFIED` only.
5. Candidate tag decision (item 22) — recommended `v0.1.0-rc.1` first; owner's call.

Not a blocker: the final artifact values. Run `34860902181` is green for the candidate and its
names, sizes and hashes are recorded in `0.1.0-readiness.md`, `0.1.0-handoff.md` §3,
`risk-register.md` §4 and `0.1.0-final-report.md`.
