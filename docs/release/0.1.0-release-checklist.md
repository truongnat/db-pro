   §8). Extraction, launch and file-level state reuse are already done, including on the
   CI-produced artifact of run `34860902181`. **No automated or CLI-level evidence can tick this
   item.**
2. Runtime evidence for V01-01…V01-05, or an explicit decision to release without it. The
   `v01-runtime` pass narrowed the PostgreSQL half but cannot close the native-UI/visual half.
3. Windows/Linux runtime (`R-WINLINUX`) — requires hosts; `BUILD_VERIFIED` only.
4. Candidate tag decision (item 22) — recommended `v0.1.0-rc.1` first; owner's call.
5. Owner decisions enumerated in `docs/release/0.1.0-human-decisions.md` (`HD-002`…`HD-008`),
   including the `F1` `pg_restore` version-skew disposition and acceptance of the SSH/backup
   unqualified status. None is decided in this pass.
