# DB Pro 0.1.0 Release Checklist

**Created:** 2026-08-09
**Baseline:** `9a7fab7`
**Target:** Release Candidate — polished, stable Database IDE with Agent-ready architecture

---

## Release Scope Classification

### RELEASE BLOCKER (P0)

Must fix before tag. Zero tolerance.

- [x] ActionExecution terminal states are immutable (cancelled cannot become completed)
- [x] Confirmation store must not orphan prepared invocations
- [ ] No password/secret in console, audit events, persisted state, or error dumps
- [ ] Destructive SQL confirmation cannot be bypassed
- [ ] Cancel actually stops backend execution
- [ ] No data loss on disconnect/reconnect
- [ ] App starts reliably on all target platforms

### RELEASE REQUIRED (P1)

Must fix before tag. Directly affects user-facing correctness.

- [ ] Query execution: single SELECT, multi-statement, run-all
- [ ] Statement-aware execution (current statement under cursor)
- [ ] Selection execution (Cmd/Ctrl+Enter with selection)
- [ ] Explain / Explain Analyze
- [ ] SQL formatting
- [ ] Result grid renders correctly
- [ ] Query history updates
- [ ] Export paths (CSV, Excel where implemented)
- [ ] Connection lifecycle: create/test/connect/disconnect/reconnect/delete
- [ ] PostgreSQL connect with bad credentials shows useful error
- [ ] SQLite open/missing file handling
- [ ] Explorer metadata: schemas, tables, views
- [ ] DB Object: Data, Columns, Indexes, Relations, DDL tabs
- [ ] Workspace tabs tied to connection lifecycle
- [ ] Error handling: useful DB errors, no blank screens
- [ ] Read-only/safety protection
- [ ] Keyboard shortcuts: Cmd+Enter, Cmd+Shift+Enter, F5, Escape
- [ ] Quick Open / Command Palette routing
- [ ] Postgres type mapping: INT2/INT4/INT8/FLOAT4/FLOAT8/NUMERIC/BOOL/TEXT/UUID/DATE/TIMESTAMP/JSON/JSONB/BYTEA/NULL
- [ ] Empty states have context/action (no blank panels)

### POST-0.1

Deferred to future releases. Must not be exposed as working features.

- Agent backend / AI assistant
- MCP server
- Advanced schema mutation tools
- Full Agent automation
- Additional database drivers beyond PostgreSQL/SQLite
- Data/Schema actions marked `not_implemented`

### EXPERIMENTAL / NOT RELEASE BLOCKING

May ship in preview or coming-soon state.

- Agent workspace panel (Preview / Coming Soon)
- Action Catalog entries marked unavailable
- Future MCP integration points

---

## Release Rules

1. **Never expose a fake-success feature.**
2. Not-implemented actions must be hidden, disabled, or clearly marked Preview/Coming Soon.
3. No MCP server shipped in 0.1.0.
4. No new database drivers added.
5. No major new features added during freeze.
6. Version locked at `0.1.0` across all manifests.
