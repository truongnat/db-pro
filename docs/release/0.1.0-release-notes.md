# DB Pro 0.1.0 — Release Notes

**Release Date:** 2026-08-XX
**Version:** 0.1.0
**Platforms:** macOS, Windows, Linux

---

## What is DB Pro?

DB Pro is a premium desktop Database IDE with an Agent-native architecture. It provides a professional workspace for connecting to databases, exploring schemas, writing SQL, and managing query workflows — all in a polished native desktop experience.

## Highlights

### Database Connectivity
- **PostgreSQL** — full connection lifecycle: create, test, connect, disconnect, reconnect
- **SQLite** — file-based connection with open/reopen support
- Secure credential storage via OS keyring (with encrypted fallback for development)

### Schema Explorer
- Tree-view explorer with schemas, tables, and views
- Metadata introspection with refresh
- DB Object workbench with tabs: Data, Columns, Indexes, Relations, DDL

### Query Workbench
- **Monaco SQL editor** with syntax highlighting
- **Statement-aware execution** — runs the statement under your cursor
- **Selection execution** — run only the selected SQL
- **Multi-statement execution** — run entire scripts
- **Explain** and **Explain Analyze** support
- **SQL formatting** via sql-formatter
- **Result grid** with row count and timing
- **Query history** with favorites
- **Export** results to CSV and Excel

### Workspace
- Multi-tab workspace with query and table tabs
- Pin/unpin tabs, preview mode
- Workspace persistence across sessions
- Quick Open (Cmd/Ctrl+P) for fast navigation
- Command Palette (Cmd/Ctrl+Shift+P) for actions

### Safety
- **Destructive query confirmation** — DROP, TRUNCATE, DELETE without WHERE require explicit approval
- **Read-only connection mode** — blocks mutations at the engine level
- SQL safety classifier with CTE awareness

### Keyboard Shortcuts
- Cmd/Ctrl+Enter — execute current statement / selection
- Cmd/Ctrl+Shift+Enter — run all statements
- F5 — run all
- Escape — cancel running query

### Agent-Ready Architecture
- Action Platform with canonical runtime, confirmation lifecycle, and audit trail
- Command Palette integration via action-to-command adapter
- Agent workspace panel (Preview / Coming Soon)
- MCP integration points designed but not shipped in this release

## Known Limitations

- Data grid row editing (insert/update/delete) is not yet wired to the backend
- Schema DDL execution actions are defined but not yet connected
- Agent assistant is not functional (Preview only)
- MCP server is not included
- No code signing on release artifacts (unsigned builds)
- Only PostgreSQL and SQLite drivers are supported

## Tech Stack

- **Tauri 2** — native desktop shell
- **Rust** — backend services, database drivers
- **React 19** + **TypeScript** — frontend
- **Vite** — build tooling
- **shadcn/ui** + **Radix** — component library
- **Tailwind CSS 4** — styling
- **Monaco** — SQL editor
- **TanStack Router** — routing
- **Zustand** — state management

## What's NOT in 0.1.0

- Production Agent assistant
- MCP server
- Additional database drivers (MySQL, etc.)
- Advanced schema mutation tools
- Full data grid CRUD

These are planned for future releases.
