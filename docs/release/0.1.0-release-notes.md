## What is DB Pro?

DB Pro is a desktop Database IDE with an Agent-ready architecture. It provides a focused workspace for connecting to databases, exploring schemas, writing SQL, inspecting objects, viewing/editing table data, and managing query workflows.

## Highlights

### Database Connectivity

- PostgreSQL connection lifecycle: create, test, connect, disconnect, reconnect
- SQLite file-based connections with native desktop file picker wiring
- Secure credential storage using OS keyring with encrypted fallback support
- Startup reconnect source flow for previously active connections

### Schema Explorer

- Explorer tree with schemas, tables, and views
- Targeted metadata refresh per connection
- Data-first table/view navigation
- DB Object workbench sections: Data, Columns, Indexes, Relations, DDL inspection

### Query Workbench

- Monaco SQL editor
- Statement-aware execution under the cursor
- Selection execution
- Run-all / multi-statement execution
- Split Run button: direct Run + options dropdown
- Explain
- SQL formatting
- Query history
- Result grid with timing/row metadata
- Query cancellation via Stop / Escape flow

### Data Grid

- Virtualized row rendering
- Filtering, sorting, pagination
- Column resizing with per-tab/resource layout state
- Row selection and scoped keyboard copy
- Copy cell / row / column name actions
- Clear read-only feedback for tables without primary keys
- PK-based staged row updates
- PK-based staged row deletes
- Patch-style updates: only changed columns are sent to the backend
- Multiple edits to the same row compose as a single logical patch
- Stable staged revision identities for partial success/failure and in-flight mutation safety
- Confirmation before applying staged destructive changes

### Workspace

- Multi-tab query/object workspace
- Preview tabs and permanent/pinned tabs
- Compact inactive pinned tabs
- Collision-aware object titles across schemas/connections
- Orphan-tab recovery with Change Connection / Close
- Workspace persistence
- Quick Open (`Cmd/Ctrl+P`)
- Command Palette (`Cmd/Ctrl+Shift+P`)

### Safety

- Destructive query confirmation in the canonical Action Platform path
- Backend read-only policy for mutation operations
- Stable query execution/cancellation identity
- Staged data mutation IDs prevent successful/failed snapshots from clearing unrelated pending work

### Agent-ready Architecture

- Action Platform with typed execution lifecycle
- Confirmation/cancellation lifecycle
- Command Palette integration
- Agent workspace panel is Preview only
- MCP server is intentionally not shipped in 0.1.0

## Known Limitations

- Complete row insertion workflow is not shipped in 0.1.0.
- Data editing requires a primary key; no-PK tables are read-only in the grid.
- Advanced schema mutation/DDL execution workbench is deferred; DDL inspection is available.
- Users/roles workbench is deferred.
- Agent assistant is Preview only and does not provide production Agent execution.
- MCP server is not included.
- SSH tunnel plumbing exists but is not yet end-to-end verified across all release targets; do not treat it as a fully qualified release capability until that verification is complete.
- Release artifacts are currently unsigned unless signing/notarization is added before distribution.
- Only PostgreSQL and SQLite are supported in this release.
