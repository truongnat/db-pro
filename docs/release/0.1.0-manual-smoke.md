# DB Pro 0.1.0 — Manual Smoke Checklist

**Estimated time:** 10–15 minutes
**Prerequisites:** Running PostgreSQL instance, SQLite fixture file

---

## Startup

- [ ] App launches from dock/taskbar/menu
- [ ] Splash screen appears with DB Pro branding
- [ ] Splash disappears and main window loads
- [ ] No blank screen or frozen UI
- [ ] No console errors/panics

## Connection — PostgreSQL

- [ ] Open Connection Dialog
- [ ] Fill PostgreSQL credentials (host, port, database, user, password)
- [ ] Test Connection → success feedback
- [ ] Connect → Explorer loads schemas/tables
- [ ] Status bar shows connected state
- [ ] Disconnect → Explorer clears
- [ ] Reconnect → Explorer reloads
- [ ] Bad password → useful error message (no crash)
- [ ] Bad host → timeout/error message (no crash)

## Connection — SQLite

- [ ] Open Connection Dialog → select SQLite
- [ ] Choose file → connect
- [ ] Explorer loads tables
- [ ] Query SQLite → results render
- [ ] Missing file → useful error

## Explorer

- [ ] Schemas expand/collapse
- [ ] Tables list under schema
- [ ] Views list under schema (if present)
- [ ] Long table names display correctly (no truncation crash)
- [ ] Empty schema shows empty state (not blank)
- [ ] Metadata refresh works

## DB Object Workbench

- [ ] Open table → Data tab renders rows
- [ ] Columns tab shows column info
- [ ] Indexes tab shows indexes
- [ ] Relations tab shows foreign keys
- [ ] DDL tab shows CREATE TABLE statement
- [ ] Empty table → data grid shows empty state with context

## Query Editor

- [ ] Open new query tab
- [ ] Monaco editor loads
- [ ] Type `SELECT 1 AS test`
- [ ] Cmd/Ctrl+Enter → executes → result appears
- [ ] Type multiple statements separated by `;`
- [ ] Cmd/Ctrl+Shift+Enter → run all → multiple results
- [ ] F5 → run all works
- [ ] Select partial SQL → Cmd/Ctrl+Enter → executes selection only
- [ ] Invalid SQL → useful DB error message (not blank)
- [ ] Empty editor + execute → no crash, useful feedback

## Safety / Confirmation

- [ ] Type `DROP TABLE test_table`
- [ ] Execute → confirmation dialog appears
- [ ] Reject → backend NOT called → no execution
- [ ] Confirm → executes (or useful error if table doesn't exist)
- [ ] Type `DELETE FROM users` (no WHERE) → destructive confirmation
- [ ] Read-only connection → mutation blocked

## Cancel

- [ ] Run a long query (e.g., `SELECT pg_sleep(30)`)
- [ ] Click Stop / press Escape → query cancels
- [ ] Status returns to idle
- [ ] No frozen state or ghost execution

## Explain

- [ ] Run `EXPLAIN SELECT 1` → explain plan renders
- [ ] Explain output is readable and formatted

## Format SQL

- [ ] Write messy SQL → click Format → SQL reformatted

## Query History

- [ ] Execute queries → history updates
- [ ] History entries show SQL, timing, row count
- [ ] Click history entry → loads SQL into editor

## Export

- [ ] Execute query → export result as CSV
- [ ] Export file downloads correctly

## Workspace Tabs

- [ ] Open multiple tabs (query + table)
- [ ] Switch between tabs
- [ ] Close tab → adjacent tab activates
- [ ] Pin/unpin tab

## Quick Open / Command Palette

- [ ] Cmd/Ctrl+P → Quick Open opens
- [ ] Search for table → opens table
- [ ] Cmd/Ctrl+Shift+P → Command Palette opens
- [ ] Search for command → executes

## Keyboard Shortcuts

- [ ] Cmd/Ctrl+Enter → execute current
- [ ] Cmd/Ctrl+Shift+Enter → run all
- [ ] F5 → run all
- [ ] Escape → cancel execution

## Agent Panel

- [ ] Agent panel visible
- [ ] Shows "Coming soon" / Preview state
- [ ] No fake message sending

## Status Bar

- [ ] Shows connection status
- [ ] Shows row count after query
- [ ] Shows timing after query

## Restart

- [ ] Close app → reopen
- [ ] Workspace tabs restored
- [ ] Connection state acceptable
- [ ] No data loss

## Visual

- [ ] Logo/branding correct in activity bar
- [ ] No horizontal page overflow at 1280x720
- [ ] No microscopic text
- [ ] No emoji icons
- [ ] No broken layout
