## Signing / Notarization

No release signing secrets are currently configured.

If `0.1.0` is published unsigned:
- macOS users may receive Gatekeeper warnings and may need manual approval.
- Windows users may receive SmartScreen warnings.
- Linux packages are not GPG-signed unless separately configured.

For a broadly distributed production release, add:
- Apple Developer ID + notarization
- Windows code-signing certificate
- Optional Linux package signing

**Current classification:** accepted P2/known limitation only if the owner explicitly accepts unsigned 0.1.0 distribution.
