## 3. What the final run does NOT prove

Stated explicitly, so no reader over-reads this report:

- **No interactive GUI behaviour.** No window has ever been rendered or interacted with on a
  packaged build. Window rendering, Settings navigation, UI connection creation, `SELECT 1;` and
  clean-close exit are `NOT VERIFIED` (`14-install-smoke.txt` §7.7; runbook §8).
- **No Windows or Linux runtime.** No host exists; both platforms are `BUILD_VERIFIED` /
  `PACKAGE_VERIFIED` and stay `RUNTIME_UNVERIFIED`.
- **No signed or notarized artifact.** All three are `UNSIGNED`; the OS security warnings are
  documented in the release notes.
- **No license.** Nothing may be presented as licensed for public use.
- **V01-01…V01-05 runtime evidence remains incomplete** (`EVIDENCE_GAP` for 01/02/04/05,
  `PARTIAL` for 03) and the manual desktop smoke is **not run** (0 of 165 items) — a green build
  run does not change either.
- **The install smoke bypassed a pre-existing keyring stall** with a placeholder `GROQ_API_KEY`
  (`R-KEYRING-STALL`, LIM-018), so it does not evidence a plain double-click launch on a machine
  with a stored key.
