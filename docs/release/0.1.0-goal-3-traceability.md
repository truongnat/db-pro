## 5. Hướng dẫn bàn giao

### 5.1 Chạy lại 6 cổng chất lượng (local)

```bash
cargo fmt --all -- --check
cargo check --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace                 # kỳ vọng: 815 passed / 0 failed / 19 ignored
cargo build --release --locked -p db-pro-native
bash .skills/perf-audit/scripts/perf-scan.sh   # kỳ vọng: 4 passed / 0 warnings / 0 failed
```

Lưu ý: toolchain bị ghim trong `rust-toolchain.toml` (1.95.0). 19 test `ignored` **không** được
tính là pass — 18 test `pg_integration` cần `DATABASE_URL`, 1 test SSH backup cần 9 biến
`DB_PRO_SSH_*`.

### 5.2 Chạy lại release pipeline

```bash
gh workflow run release.yml -f ref=<sha>
```

- Pipeline: `Resolve release candidate` → `Pre-flight checks` → `Build (macOS|Windows|Linux)` →
  `Package (macOS|Windows|Linux)` → `Assemble SHA256SUMS`.
- Workflow chạy với `permissions: contents: read`, **không dùng secret**, không tạo Release,
  không tự push tag. Tag `v*` (nếu push) phải khớp version trong `crates/native-app/Cargo.toml`
  (`0.1.0`).
- Lịch sử các run và lỗi đã sửa: `docs/release/0.1.0-final-report.md` §4.

### 5.3 Tải và kiểm tra artifact

```bash
gh run download 34860902181            # hoặc run mới nhất
shasum -a 256 -c SHA256SUMS.txt        # macOS/Linux
Get-FileHash -Algorithm SHA256 <file>  # Windows
```

### 5.4 Chạy lại install smoke

1. Giải nén artifact macOS: `tar -xzf db-pro-v0.1.0-macos-arm64.tar.gz -C <dir>`.
2. **Runbook cho người có phiên desktop:** `docs/release/evidence/v01-06/14-install-smoke.txt` §8
   (12 bước: launch → window → Settings → tạo SQLite connection → `SELECT 1;` →
   `SELECT * FROM items;` → ⌘Q → relaunch → kiểm tra state).
3. Kiểm tra state dir phải là `~/Library/Application Support/DB Pro/` (macOS), **không** phải
   `/.db-pro-data`; ghi lại `stat -f "inode=%i size=%z mtime=%Sm"`.
4. Ghi kết quả vào `docs/release/0.1.0-manual-smoke.md`, rồi cập nhật `0.1.0-handoff.md` §5 và
   `0.1.0-readiness.md`. **Không tick bất cứ bước nào chưa thực sự chạy.**

### 5.5 Tag và rollback

```bash
git tag -a v0.1.0-rc.1 $(git rev-parse HEAD) -m "DB Pro 0.1.0-rc.1"   # khuyến nghị trước
git push origin v0.1.0-rc.1
# sau khi smoke đạt:
git tag -a v0.1.0 $(git rev-parse HEAD) -m "DB Pro 0.1.0"
git push origin v0.1.0
# rollback (khi chưa có Release page):
git push origin :refs/tags/v0.1.0 && git tag -d v0.1.0
```

Không bao giờ force-push `main`; không đặt tag trên `fbf9fda` (chứa blocker `R-STATE-DIR`).
Chi tiết đầy đủ: `docs/release/0.1.0-handoff.md` §8–§9.
