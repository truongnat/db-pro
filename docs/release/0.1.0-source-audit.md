## Credential Security

### Frontend
- **Connection store** persists only `explorerConnectionId` via `partialize` — no passwords
- **Workspace store** persists tabs with results/status stripped — no credentials
- **Query history store** persists entries/favorites — SQL text only, no passwords
- Password flows through form state → Tauri command → backend; never persisted in frontend

### Backend
- **KeyringVault** uses OS keyring as primary secret store
- Fallback disabled by default; requires explicit `with_fallback()` opt-in
- Fallback encryption: Argon2id key derivation + AES-256-GCM
- Fallback file permissions: 0600 (Unix)
- Atomic writes via temp file + rename
- Debug output redacts service name

### Verdict: SAFE for release
