- Issue: **#54** ([Gate 5][A4] Lock Rust/Tauri/frontend provider-value DTO serialization contract) —

- Boundary under test: the whole result payload — the Tauri `QueryResultDto`

  `UiQueryResult` (`crates/ui/src/runtime.rs:555`) on the native channel.

## 1. What existed before

The isolated pieces were pinned and the composite payload was not:

- `CellValueDto` (`crates/tauri-app/src/dto.rs:320`) is an adjacently tagged enum
  (`tag = "type", content = "value"`) whose `Int64` leaves as a string
  (`cell_value_dto_int64_boundary_values_serialize_as_strings`, `:1375` before this change).
- No test serialized a **whole result**: `QueryResultDto` was covered by no test at all
  (`grep -rn "QueryResultDto" --include='*.rs' crates/` reached only production code —
  `crates/tauri-app/src/commands/query.rs:5,21,90`).
- The only checked-in contract fixture was the introspection one
  (`crates/tauri-app/tests/fixtures/introspect-contract.json`).
- The shipping channel is not serde at all: `map_cell` (`crates/native-app/src/translate.rs:660`)
  and `map_query_result` (`:847`) build the in-process `UiQueryResult`, and no test asserted the
  field-by-field or class-by-class mapping.

The issue's "update frontend TypeScript DTO type to mirror emitted JSON exactly" half is void: the
React frontend was retired on 2026-09-11 (`_archive/README.md`; #60/#63 superseded), so the shipping
consumer is the native UI.

## 2. The contract tests

One representative whole result carries **every value class** in the contract — A1
integer/numeric (`int64`, `decimal`), A2 temporal (`datetime` with `Z`, `datetime` without,
`date`, `time`, `time+offset`), A3 structured/fallback (`json`, `uuid`, `bytes`, `interval`,
`inet`, `text`) plus `bool`/`float64`/`null` — in a 15-column, two-row payload whose second row is
all-NULL.

| Test | File | What it pins |
|---|---|---|
| `query_result_dto_serializes_the_locked_camel_case_shape` | `crates/tauri-app/src/dto.rs` | the exact sorted top-level key set (`columns`, `durationMs`, `rowCount`, `rows` — an added *or* omitted field fails); the three column keys (`name`, `dataType`, `nullable`); rows as arrays of cells with one cell per column |
| `query_result_dto_covers_every_value_class_tag` | `crates/tauri-app/src/dto.rs` | the ordered tag list of the mixed row (`int64`, `bool`, `float64`, `decimal`, `text`, `json`, `uuid`, `datetime`, `datetime`, `date`, `time`, `time`, `interval`, `inet`, `bytes`) — a class collapsed into `text` fails; every NULL cell is `{"type":"null"}` with **no** `value` key |
| `query_result_dto_never_exposes_precision_sensitive_values_as_numbers` | `crates/tauri-app/src/dto.rs` | `9007199254740993` and `12345678901234567890.12345` leave as JSON **strings**, while `float64` stays a JSON number |
| `query_result_dto_matches_the_checked_in_contract_fixture` | `crates/tauri-app/src/dto.rs` | `serde_json::to_string_pretty` is byte-identical to the checked-in fixture, and every tagged cell in it deserializes back through `CellValueDto` and re-serializes to the same JSON (round-trip without shape ambiguity) |
| `map_cell_keeps_one_ui_class_per_domain_value_class` | `crates/native-app/src/translate.rs` (tests) | the Rust↔UI mapping for all 14 domain variants: `Null→UiCell::Null`, `Bool→Boolean`, `Int64`/`Float64`/`Decimal→Number(<exact text>)`, text classes→`Text`, `Bytes→Bytes("\\x00ff10")`, `Json→Json` |
| `query_result_translation_keeps_every_field_and_value_class` | `crates/native-app/src/translate_tests.rs` | the shipping-channel field mapping: `row_count`, `duration_ms`, `columns[].name/data_type/nullable` and the cell vector all survive translation with the canonical decimal text intact |

**Checked-in fixture:** `crates/tauri-app/tests/fixtures/query-result-contract.json` — the recorded
whole-result shape, generated by serializing the actual DTO structs and then re-asserted
byte-for-byte by the fixture test, so it is emitted shape rather than a hand-written copy.
