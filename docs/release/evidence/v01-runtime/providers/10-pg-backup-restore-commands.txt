  SCOPE CAVEAT: this is a CLI-level verification that the documented
  pg_dump/pg_restore dependency is satisfiable on this host, using the
  same PATH tools the application shells out to. It is NOT a GUI backup test:
  no window was rendered and the app's Backup action was never clicked.
