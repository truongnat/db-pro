### 1.3 An ninh & An toàn dữ liệu
- **Điểm mạnh:**
  - Phân loại an toàn câu lệnh theo ngữ nghĩa (lexical safety classification), ngăn chặn `DELETE/UPDATE` không có `WHERE`.
  - Batch đa câu lệnh tự động bọc trong transaction nguyên tử; cấm `BEGIN/COMMIT/ROLLBACK` lồng trong batch.
  - CSV/Clipboard export có `guard_csv_field` chống CSV Formula Injection (`=`, `+`, `-`, `@`).
  - SQLite backup sử dụng `VACUUM INTO` kèm `PRAGMA quick_check` và dọn dẹp sidecar WAL/SHM an toàn.
  - SQLite sample seeding dùng `SQLITE_OPEN_NOFOLLOW`, kiểm tra `application_id` và marker table chống symlink hijacking.
- **Finding cần xác nhận chính sách (Query History):** `query_editor.query_history_entries` được tuần tự hóa nguyên bản vào `app.ron` qua eframe storage (`"dbpro.native.query-history-v1"`). Nếu người dùng chạy câu lệnh chứa thông tin xác thực (`CREATE USER ... PASSWORD '...'`), câu lệnh này được lưu nguyên văn. Cần quyết định chính sách: giữ nguyên văn lịch sử truy vấn (như các DB IDE chuẩn) hay áp dụng redaction.
- **CLI Option Injection (SSH Tunnel):** Tại `crates/infrastructure/src/ssh/tunnel.rs:86, 114`, chuỗi `format!("{}@{}", config.user, config.host)` được truyền dưới dạng đối số argv cho `ssh` mà thiếu cờ phân tách `--`, đồng thời `validate_ssh_tunnel` chưa từ chối tên user/host bắt đầu bằng dấu `-`. Nếu cấu hình chứa giá trị này (ví dụ `-oProxyCommand=...`), `ssh` có thể hiểu nhầm là tùy chọn CLI (đây là rủi ro CLI option injection, không phải shell metacharacter injection).

### 1.4 Packaging & Release Engineering
- **Shutdown Crash (R-01 - Confirmed Blocker):** Trên binary release macOS, việc đóng cửa sổ native bằng phím tắt hoặc nút đóng làm ứng dụng thoát với mã `-6` (`SIGABRT`), ghi nhận `NSRangeException` từ `_NSTouchBarFinderObservation`. Nguyên nhân gốc và phương án khắc phục đang chờ tái hiện và điều tra sâu ở tầng winit/AppKit.
- **Pháp lý artifact (R-02 - Blocker):** Script `package-macos.sh` chỉ đóng gói binary và file note, thiếu file `LICENSE` và bundle `THIRD_PARTY_NOTICES.md`. File `README-INSTALL.txt` có đoạn mô tả chưa khớp với giấy phép MIT.
- **Phân phối:** Binary được ký ad-hoc, chưa có chữ ký Apple Developer ID hoặc ticket Notarization (Gatekeeper từ chối với `spctl` exit 1).
- **Hạ tầng CI:** Workflow `.github/workflows/release.yml` chưa chạy trên candidate SHA này; chưa có artifact kiểm chứng cho Windows x86_64 và Linux x86_64.

### Nhóm 1: Blockers kỹ thuật & pháp lý (Bắt buộc trước khi tag release)
