# DB Pro — Native Desktop Design System This is the single source of truth for DB Pro visual language. DB Pro is a native Rust/egui database IDE for PostgreSQL and SQLite. Stitch screens are design references; do not style it like a web SaaS dashboard. Optimize for dense real work, keyboard use, precise data reading, and stable panes. Keep token names and values aligned with `crates/ui/src/theme.rs` (`DbProTheme`). ## Brand and visual principles - Quiet, technical, precise, dark-first workstation; light theme remains a first-class counterpart. - Editor and result grid are the primary work surfaces. Hierarchy comes from surface planes, separators, type, and selection—not decorative cards. - High information density, short labels, clear focus, minimal motion. Avoid visual noise. - Native desktop conventions: resizable panes, compact controls, persistent status bar, keyboard-first navigation.
