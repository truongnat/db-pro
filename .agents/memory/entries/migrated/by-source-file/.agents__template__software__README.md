# Template phát triển phần mềm

Chọn template tương xứng với công việc; không coi đây là thủ tục bắt buộc cho mọi chỉnh sửa.

- `feature-spec.md` — vấn đề, phạm vi, yêu cầu và tiêu chí chấp nhận.
- `implementation-plan.md` — các bước thay đổi, rủi ro và kiểm chứng.
- `technical-design.md` — thành phần, luồng dữ liệu và thiết kế ảnh hưởng nhiều khu vực.
- `test-plan.md` — hành vi, edge case và bằng chứng kiểm thử.
- `bug-investigation.md` — tái hiện, giả thuyết, nguyên nhân gốc và cách sửa.
- `code-review.md` — tính đúng đắn, bảo mật, regression và phát hiện.
- `security-review.md` — auth, dữ liệu nhạy cảm, trust boundary (`security-review` skill).
- `release-checklist.md` — rollout, smoke test và rollback.
- `adr.md` — quyết định kiến trúc lâu dài và trade-off.
- `incident-postmortem.md` — ảnh hưởng, dòng thời gian, nguyên nhân gốc và phòng ngừa.
- `handoff.md` — ngữ cảnh đủ để phiên/agent tiếp theo tiếp tục công việc.
- `retrospective.md` — kết quả và cải tiến quy trình có thể hành động.
- `memory-evaluation.md` — kiểm tra có thể lặp lại để đánh giá khả năng truy xuất memory.
