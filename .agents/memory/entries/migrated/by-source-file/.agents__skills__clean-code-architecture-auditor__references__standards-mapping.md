|---|---|---|
| ISO/IEC/IEEE 29119 | Testing processes, documentation, techniques | Plans, tests, results, incident reports |
| ISO/IEC 25010 | Quality model | Attribute and risk coverage |
| ISTQB CTFL | Risk-based testing and design techniques | Applied technique per case |
| WCAG 2.2 | Accessible web UI where applicable | Criteria and manual/automatic checks |
| OWASP ASVS / MASVS | Security verification | Versioned controls and measured results |
| ISO 9241 | Contextual usability and human-centered design | Task outcomes in supported contexts |
