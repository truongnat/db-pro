# Risk-Based Master Test Plan

1. Context, scope, critical user journeys, stakeholders.
2. Test basis: requirements, architecture, contracts, defects.
3. Quality risks: impact 1–5 × likelihood 1–5; priority, owner.
4. Levels: unit, integration, system, acceptance; rationale.
5. Test techniques and selection criteria.
6. Environment matrix, safe fixtures, roles and dependencies.
7. Entry/exit criteria, quality budgets and required evidence.
8. Schedule, responsibilities and blocked-environment contingencies.
9. Traceability requirement → risk → test → evidence → defect.
10. Final release sign-off criteria.
