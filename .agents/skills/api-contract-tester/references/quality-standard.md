# QA Quality Standard

Use ISO/IEC/IEEE 29119 for process/documentation, ISO/IEC 25010 for quality attributes, ISTQB for test design methods, WCAG 2.2 where applicable for accessibility, OWASP ASVS/MASVS for security verification, and ISO 9241 for usability. These are reference frameworks, not claims of certification.

Evidence classifications: CONFIRMED (reproduced), LIKELY (static trace), RISK (hypothesis), DESIGN CONCERN, PASS (executed), FAIL (executed), BLOCKED, NOT TESTED, N/A (reason required).

Severity: S0 catastrophic, S1 serious loss/security/key journey failure, S2 material degradation, S3 cosmetic. Priority P0–P3 is urgency, not severity.

Never fabricate tests, screenshots, timings, compliance or tool results. Never touch production destructively or reveal secrets. Distinguish source inspection and real interactive testing.
